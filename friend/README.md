# 软考打卡 · 通用版（给朋友用）

单文件网页，打开就能用，**不需要装东西、不需要注册、不联网**（除了首次下载这个文件）。

## 给她怎么用

1. 把 `软考打卡.html` 发给她（微信 / QQ 都行，就是个普通文件）。
2. 她存到手机上，**用浏览器打开**（不要用微信内置浏览器，用 Chrome / Safari / Edge）。
3. 建议加到主屏幕：Safari「分享 → 添加到主屏幕」；Chrome「菜单 → 添加到主屏幕」。之后像 App 一样点开。
4. 从 **2026-09-19（周六）** 开始，她打开就会看到当天该做的事。

## 计划怎么算的

**计划是写死在文件里的，页面按"今天"自动算该显示什么**：

- 今天（9/18）打开 → 显示「启动准备日」4 件事 + 提示 W1 从 9/21 开始
- 明天（9/19 周六）→ 同为准备日
- **9/21（周一）起 → 自动进入 W1**，本周主线、本周目标、每日晨读卡都会跟着变
- 之后每周一自动跳到下一周，一直到 2027-05-23 考试日

W1 起始日写在文件里这一行，想整体前后挪就改它：

```js
const START = new Date(2026, 8, 21);   // 注意：月份从 0 数，8 = 9 月
const START_TXT = "2026-09-21";
```

## 数据在哪（重要）

**打卡记录只存在她自己的浏览器里，不会传到任何地方，也不会传给你。**

这个文件里**没有任何联网代码**（grep 过 `fetch`/`XMLHttpRequest`/`WebSocket` 全无）。所以：

- 她的打卡、成绩、错题**只有她自己的设备能看见**
- 你打的卡她也看不见
- 换设备 / 清缓存 = 数据没了

**所以一定要提醒她：每月点一次「数据 → 导出备份（JSON）」**，存微信文件传输助手或网盘。换手机时用「导入备份」恢复。

## 回看（记录历史）

页面里新增的「回看」卡片可以翻所有打卡记录：

- 顶部 4 个数：有记录天数 / 累计完成项数 / 累计投入小时 / 当前连续天数
- **本月 / 全部** 切换：列出每一天的日期、星期、完成了哪几项（**具体文字**）、投入时长、状态、备注
- 「36 周总览」热力图：每格一天，颜色越深当天完成越多，一眼看出哪几周断了

> **技术说明**：早期版本的打卡记录里存的是**下标**（0、1、2…），一旦今天的清单变了，下标就指错人，回看时根本看不出当时做了什么。这一版改成**存文字**，并带自动迁移——她如果之前用旧版打过卡，第一次打开新版会把旧下标翻译成文字（成绩和错题本也一起带过来），不会丢数据。

## 课表

文件里保留了课表数据（来源：教务系统导出的 2026-2027-1 学期课表），会在有课的日子自动插一条提示，例如：

> 📚 05-06 计算机网络（史庆宇 · 日新楼D103）→ 今天网络课，笔记里补一句：这个考点软考怎么考？

如果她的课表和这份不一样，改代码里的 `COURSES` 数组即可（在 `<script>` 里搜 `const COURSES`），格式：

```js
{d:1, sec:"05-06", name:"计算机网络", teacher:"史庆宇", weeks:"all", room:"日新楼D103", link:true,
 note:"今天网络课 → 笔记里补一句软考对应考点"},
```

`d` 是星期（1=周一…7=周日），`weeks` 可填 `"all"` / `"odd"`（单周）/ `"even"`（双周）/ `[11,12]`（指定教学周）。

## 改成 2027 下半年考的版本

只需把 `EXAM` 那行改成下半年考试日（往年 11 月上旬），36 周计划的周次会整体跟着重算，**但内容是按上半年考试写的**，下半年考的科目与大纲可能有变，需要自己核对。
