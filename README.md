一个单文件的学习计划 App：把三条线合成 41 周，每天告诉你该走哪一步，并能打卡记录。

## 六个页签

- **概览**：三个倒计时、总体进度、今天该怎么走（按真实课表算出的可用时间与各轨任务量）
- **今日打卡**：按当天自动生成清单（晨读卡 / 晚课线 / 写代码 / 铁律 / 当日联动课提示），勾选即存
- **周计划**：41 周逐周展开，含软考/AI/六级/维护/里程碑五栏
- **复盘数据**：软考上午下午 + 六级总分曲线、42 周投入热力图、月度自检表、周复盘模板
- **错题 / 卡点**：按轨分类，可导出 Markdown
- **节奏与速查**：课表（⭐标注软考联动课）、固定周节奏、12 张晨读卡轮转、高频公式与常见坑，**考试日期可改**

## 数据说明（重要）

**数据只存在你打开它的那个浏览器里**（localStorage），不上传任何服务器。

但 localStorage 按「协议 + 主机 + 端口」隔离，所以：

- 这个网页地址一份数据
- 本地 `file://` 打开是另一份
- 手机主屏图标是第三份（在手机里）

**它们互不相通。** 要同步就用 App 里的「数据 → 导出全部数据（JSON）」，在另一边「导入备份」。

建议固定用一个地址当主用（推荐上面那个在线地址），并且**每月导出一次**备份到微信/网盘 —— 浏览器清缓存会带走数据。

## 计划逻辑

- **软考与 AI 互相喂**，不抢时间：数据结构 → KMP / 图算法；计算机网络 → RAG 的检索分层；OS 调度与 PV 操作 → 并发与上下文预算
- **周三全天停摆**（03-04 + 05-06 + 07-08 三节连堂），不排学习任务
- **周一降载**（组成原理 + 计算机网络两门课，8:00–16:00 都在上课），写代码块挪到周二晚
- **整块攻坚只排周六日**，工作日只做小块；软考整卷固定在周五（上午卷）与周六（下午卷）
- 周任务量约 20 小时，与「工作日小块 + 周末整块」的真实可用时间对齐

## 技术

单个 HTML 文件（约 95 KB），**零依赖、零构建**：原生 JavaScript，数据存 localStorage，图表是手写 Canvas。PWA 图标由 `tools/make-icons.mjs` 用纯 Node 现画（不依赖任何图形库）。

```
index.html              主入口（与 三轨学习计划.html 逐字节一致）
三轨学习计划.html         同一份文件，中文名便于本地双击
manifest.webmanifest    主屏安装清单
icon-180/192/512.png    主屏图标
tools/make-icons.mjs    重新生成图标
tools/sync-index.mjs    保持 index.html 与中文名那份一致（--check 只校验不写）
```

改完页面记得跑一次 `node tools/sync-index.mjs`，否则 `index.html` 会和中文名那份脱节。
